🤖 AlgoBot – AI Chatbot

AlgoBot is an intelligent AI chatbot built with HTML, Tailwind CSS, and JavaScript. It leverages the Gemini API to provide accurate and dynamic responses, offering users a seamless conversational experience.

This project demonstrates frontend development skills, API integration, interactive UI design, and AI-powered solutions, making it a perfect showcase for recruiters.

✨ Key Features
💬 AI-Powered Chat
Interact with a smart AI chatbot using natural language
Real-time responses via Gemini API
Perfect for learning, problem-solving, and general queries
🖥 Interactive User Interface
Modern responsive design with Tailwind CSS
Smooth chat animations and real-time updates
User-friendly input and message display
⚡ Frontend Functionality
Entirely HTML, CSS, JavaScript-based
Dynamic message rendering for chat conversation
Responsive design compatible with desktop, tablet, and mobile

🧰 Tech Stack
🔧 Technology	📝 Purpose
HTML5	Structure & layout
Tailwind CSS	Styling & responsive UI
JavaScript	Application logic & interactivity
Gemini API	AI chatbot responses & data processing
